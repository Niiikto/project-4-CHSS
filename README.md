
# WellnessIQ
### Senior Wellness & Predictive Analytics Platform

An end-to-end Data Science portfolio project using the
2019–2020 Canadian Health Survey on Seniors (CHSS).

## Business Problem

How can healthcare and community organizations use
data to identify population groups experiencing
higher levels of loneliness and prioritize resources?

## Project Objectives

1. Analyze loneliness patterns among Canadian seniors.
2. Examine geographic and demographic differences.
3. Identify factors associated with loneliness.
4. Develop predictive machine learning models.
5. Build an interactive business intelligence dashboard.
6. Translate analytical findings into recommendations.

## Technologies

- Python — pandas, NumPy, scikit-learn
- SQL — SQLite
- R — Statistical and survey-weighted analysis
- Streamlit — Interactive dashboard
- Git & GitHub — Version control

## Data Source

Statistics Canada, Canadian Health Survey on Seniors
(CHSS), 2019–2020 Public Use Microdata File.

Raw and respondent-level data are excluded from
this repository.
